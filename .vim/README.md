# Vim Config

## Keymappings

Leader key: `,`

### General

| Key | Action |
|-----|--------|
| `,r` | Reload vimrc |
| `,pi` | Plugin install |
| `,pc` | Plugin clean |
| `,h` | Find and replace |
| `,/` | Clear search highlight |
| `,c` | Toggle comment (current line or visual selection) |

### Navigation

| Key | Action |
|-----|--------|
| `Ctrl-n` | Next buffer |
| `Ctrl-p` | Previous buffer |
| `Ctrl-Shift-→` | Next tab |
| `Ctrl-Shift-←` | Previous tab |

### NERDTree

| Key | Action |
|-----|--------|
| `Ctrl-f` | Toggle NERDTree |
| `,n` | Focus NERDTree |

### Git

| Key | Action |
|-----|--------|
| `,g` | Toggle GitGutter |

### Markdown

| Key | Action |
|-----|--------|
| `,m` | Markdown preview |

### Focus

| Key | Action |
|-----|--------|
| `,,` | Toggle Goyo + Limelight |
